System Overview

This RAG (Retrieval-Augmented Generation) system combines document retrieval with LLM generation. It processes documents, creates embeddings, stores them in a vector database, and uses them to answer questions.

Data Directory ./data
Vector DB ChromaDB (./chroma_db)
Embedding Model all-MiniLM-L6-v2
LLM Ollama (gpt-oss:20b)

1. Document Loaders

The system supports multiple file formats:

def load_file(path: str) -> str: ext = os.path.splitext(path)[1].lower() if ext == ".txt" or ext == ".md": return load_txt(path) if ext == ".pdf": return load_pdf(path) if ext == ".docx": return load_docx(path)

2. Text Chunking

Documents are split into overlapping chunks to preserve context:

def chunk_text(text: str, chunk_size: int = 900, overlap: int = 120): # Simple char-based chunking with overlap chunks = [] start = 0 while start < len(text): end = min(len(text), start + chunk_size) chunks.append(text[start:end]) start = end - overlap # Overlap for context

Why overlap? Ensures important information at chunk boundaries isn't lost.

3. Embedding Generation

Each chunk is converted to a vector using SentenceTransformer:

embedder = SentenceTransformer("all-MiniLM-L6-v2") embeddings = embedder.encode(documents, normalize_embeddings=True)

These vectors capture semantic meaning, allowing similarity search.

4. Vector Storage

Chunks are stored in ChromaDB with metadata:

col.add( ids=["file.txt::chunk_0", ...], documents=[chunk_texts, ...], metadatas=[{"source": "file.txt", "chunk": 0}, ...], embeddings=[vectors, ...] )

Generation Process

Key Functions Explained

index_documents()

Main indexing function that orchestrates the entire indexing pipeline:

  • Scans ./data directory for supported files
  • Loads each file using appropriate loader
  • Chunks the text with overlap
  • Generates embeddings for all chunks
  • Stores everything in ChromaDB with metadata

retrieve(query, k=4)

Retrieves the most relevant document chunks for a query:

  • Embeds the query using the same model
  • Performs cosine similarity search in ChromaDB
  • Returns top-k chunks with metadata and distances

chat()

Interactive CLI interface that combines retrieval and generation:

while True: q = input("You: ") hits = retrieve(q, k=4) # Retrieve prompt = build_prompt(q, hits) # Build prompt ans = ollama_generate(prompt) # Generate print(ans) # Display
